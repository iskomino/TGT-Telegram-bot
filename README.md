# TGT Telegram Bot (ATU)

Бот Студенческой молодёжной организации (TGT) Азербайджанского технологического университета.
Сделан на основе бота АТУ: те же меню, языки (az / ru / en), админ-панель, защита от спама.

## Запуск
```bash
python -m venv venv
venv\Scripts\activate           # Windows (Mac/Linux: source venv/bin/activate)
python -m pip install -r requirements.txt
copy .env.example .env          # впишите BOT_TOKEN нового бота и ADMIN_IDS
python main.py
```
ВАЖНО: для этого бота создайте НОВОГО бота в @BotFather. Токен бота АТУ использовать нельзя, иначе будет `TelegramConflictError`.

## Что умеет бот
- 🎭 **Клубы**: Mentor, Debat, Psixologiya, İntellektual oyunlar, Kitab, Kino. У каждого есть описание, сədr и sədr müavini (имя, фамилия, телефон).
- 🏛 **TGT İdarə Heyəti** (Правление): руководитель **TGT İdarə Heyətinin V.M.İ.E. Sədri — Nazim Huseynov** с телефоном и 6 свободных мест для других членов Правления (показываются, когда заполнены).
- ℹ️ **О TGT**: описание, руководитель, телефон, комната, адрес и геолокация.

## Заявки в клубы, мероприятия, обращения
- **📝 Вступить**: в карточке клуба студент оставляет имя, факультет и (по желанию) телефон. Админы сразу получают уведомление с кнопками «Принять / Отклонить», студент получает ответ в боте.
  Ограничения: одна открытая заявка на клуб, не более 5 открытых в целом.
- **📅 Мероприятия**: админ создаёт событие (название, дата по Баку, место, описание, лимит), студенты записываются и за сутки получают напоминание.
  Можно оповестить всех о новом мероприятии, редактировать, видеть список записавшихся; при изменении времени или места и при отмене записавшимся приходит уведомление.
- **✉️ Обращение**: предложение, жалоба или вопрос, можно анонимно (имя не показывается админам, ответ приходит в бот). Админ отвечает прямо из бота, закрывает обращение или блокирует отправителя на 7 дней.
- **❓ FAQ («Tez-tez verilən suallar»)**: отдельная кнопка с часто задаваемыми вопросами. Вопросы показываются кнопками без номеров, ответ открывается по нажатию. При первом запуске записываются 9 исходных вопросов; дальше админ («❓ FAQ» в панели) добавляет новые, редактирует, меняет порядок (⬆️/⬇️) и удаляет. Для каждого вопроса можно добавить перевод на русский и английский (если перевода нет, показывается азербайджанский). В статистике видно, какие вопросы открывают чаще всего.
- **📰 Новости**: отдельная кнопка в меню. Админ публикует новости TGT («📰 Xəbərlər» в панели): заголовок, текст, фото и ссылка (всё, кроме заголовка и текста, необязательно). Перед публикацией показывается предпросмотр, можно опубликовать молча или сразу оповестить подписчиков. Студент видит последние 10 новостей и может подписаться на уведомления о новых (подписаться и отписаться можно в один клик).
- **✅ Посещаемость и оценки**: за час до начала организатор отмечает пришедших в админке (кнопки по списку записавшихся, плюс счётчик пришедших без записи). После мероприятия кнопка «⭐ Запросить оценки» отправляет пришедшим оценку от 1 до 5 (оценить можно один раз). В карточке события видны явка и средняя оценка, а «📊 Отчёт» в разделе мероприятий показывает итоги: число мероприятий, записавшихся, явку в процентах и среднюю оценку. Итоги прошедших мероприятий (без имён) сохраняются для отчётов и после очистки данных участников.
- **🧩 Тест «Какой клуб мне подходит?»**: в разделе клубов 6 вопросов, результат: подходящий клуб (и близкие варианты) с кнопками «Вступить» и «О клубе». В статистике видно, сколько человек прошли тест и какой клуб рекомендуется чаще всего.
- Персональные данные хранятся ограниченное время: обработанные заявки и обращения 90 дней, данные прошедших мероприятий 30 дней.

## Админ-панель (`/admin`)
Узнайте свой Telegram ID у @userinfobot и впишите в `ADMIN_IDS` (через запятую можно несколько, например Назима).
- **Klublar**: выбрать клуб → сədr / müavin → изменить имя, фамилию, телефон или «🗑 Стереть все данные» (при уходе человека). Там же можно изменить описание клуба.
- **TGT İdarə Heyəti**: 7 мест (место 1 занято руководителем). Для каждого: должность, имя, фамилия, отчество, телефон, e-mail. Пустые места пользователям не видны. Должности «TGT İdarə Heyətinin Sədri / V.M.İ.E. Sədri / üzvü» автоматически переводятся для пользователей ru/en.
- **TGT məlumatı**: комната, адрес и текст «О TGT».
- **Statistika** (включая популярность клубов) и **Kütləvi göndəriş** (рассылка).
- В любом поле «-» очищает значение. Телефон приводится к виду `+994 55 123 45 67`.

## Структура
`main.py` запуск · `config.py` настройки · `data.py` исходные данные · `content.py` логика данных ·
`db.py` SQLite (bot.db) · `texts.py` / `admin_texts.py` тексты · `handlers.py` пользователь ·
`admin.py`, `admin_extra.py` админ-панель · `middleware.py` статистика и защита от спама · `bot_profile.py` оформление бота
